# 个人简历展示与可视化后台管理系统

本项目基于您提供的个人简历模板进行了全方位升级与本地化部署，提供了**轻量级 Node.js 服务后端**以及**功能完备的现代化后台管理面板（Admin Dashboard）**。

您无需再手动修改 `index.html`，所有的简历信息、版式布局（一栏/两栏）、配色风格、模块开关均可在后台可视化编辑并一键持久化保存，前台实时同步生效。

**同时支持纯静态部署**（无需任何服务器），可一键发布到腾讯云 EdgeOne / 阿里云 OSS / GitHub Pages 等平台。

## 🚀 两种运行模式

### 模式 A：本地服务器（功能最全，推荐开发时用）

```bash
# 双击运行
start.bat

# 或命令行
npm start
```
- 前台：http://localhost:8080
- 后台：http://localhost:8080/admin/
- 数据**自动写回 `data/resume.json`**，图片上传保存到 `uploads/`

### 模式 B：纯静态托管（零成本发布，推荐上线用）

```bash
# 1. 构建静态包
npm run build:static

# 2. 部署到 EdgeOne（首次需配置 Token）
deploy-edgeone.bat

# 或手动拖拽 dist 目录到任意静态托管平台
```
- 静态环境下后台数据保存在**浏览器 localStorage**
- 编辑后点「导出」下载 `data.json`，替换站点文件重新上传即可永久生效
- 图片上传自动转为 Base64 内联（不依赖服务器）

> 同一套代码自动识别环境：检测到 `/api/resume` 可用就走服务器模式，否则自动降级为静态模式，无需维护两份。

## 🌟 核心功能特性

### 0. 简历投递记录管理（求职进度看板）
独立页面：`/admin/jobs`（本地）或 `/admin/jobs.html`（静态）

- **表格化管理**：15 个可配置字段（公司名称、公司类型、所属行业、招聘类型、招聘对象、工作地点、岗位、投递进度、更新时间、投递截止、相关链接、招聘公告、笔试情况、公司规模、备注）。
- **列显示开关**：点击「列显示」可按需勾选/隐藏任意列，一键「恢复全部列」。
- **投递进度跟踪**：状态胶囊下拉（未投递 / 已投递 / 笔试中 / 面试中 / 已 offer / 已拒绝 / 已放弃），自动统计顶部看板数量。
- **粘贴导入**：在招聘网站框选表格复制 → 点「粘贴导入」粘贴 → 自动识别制表符/多空格/竖线/逗号分隔并结构化，支持追加或替换模式。
- **CSV / Excel 互导**：支持导入本地 CSV 文件（浏览器本地读取），并可一键「导出 Excel」下载带 BOM 的 CSV，Excel 双击直接打开，无中文乱码。
- **高效编辑**：行内直接编辑、单元格长文本自动换行、一键复制整行、一键删除、全表搜索过滤、`Ctrl+S` 快捷保存、60 秒自动保存、离开页面防丢失提醒。


> ⚠️ **关于「爬取第三方站点」的说明**：项目**刻意未实现**抓取 givemeoc.com 等第三方站点的功能。原因有二：① 该站数据需登录鉴权，无法在本地服务中合法获取；② 未经授权抓取他人站点数据会违反其服务条款与 robots 协议，且可能触及《反不正当竞争法》与数据合规红线。
> **推荐替代方案（已实现且效果等同）**：在浏览器中登录并打开岗位列表页 → 鼠标框选表格内容 `Ctrl+C` → 回到本页面点「粘贴导入」`Ctrl+V` → 一键结构化入库。此方式完全合规、零配置、且支持任意招聘网站（givemeoc、应届生、牛客、各公司官网等）。

### 1. 简历版式一键切换（一栏 / 两栏）
- **两栏经典布局（双列左右式）**：原版经典排版，左侧展示个人信息、头像、技能掌握度进度条与联系方式，右侧展示教育背景、工作经历与项目经验。支持左侧悬浮固定（Side Fixed）功能。
- **一栏单列布局（自上而下居中式）**：现代极简风格，顶部名片与联系徽章，自上而下单列流动排版，层次清晰，信息聚焦，对 HR 浏览与打印导出 PDF 极其友好。
- **前后台实时切换**：后台可一键切换默认版式；前台右上角快捷工具栏亦支持随时切换预览。

### 2. 全内容可视化后台管理（无需手写 HTML）
- **基本信息**：姓名、求职职位、城市、个性签名、头像上传（支持本地图片直接选择上传到服务器，或填写外部图片链接）。
- **档案资料 (Profile)**：动态列表管理（如英语水平、计算机等级、工作年限、期望薪资等），支持新增、删除、上移下移排序。
- **联系方式 (Contact)**：手机号、邮箱、个人网站、GitHub、微信等，支持配置点击一键拨号或跳转链接。
- **专业技能 (Skills)**：技能名称与熟练度（0-100% 交互滑块），前台自动渲染为动态进度条。
- **教育经历 (Education)**：学校、专业学位、起止时间、在校表现与荣誉说明（支持 `<mark>` 高亮语法）。
- **工作经历 (Work Experience)**：公司名称、职位名称、起止时间、工作要点列表（按行输入，自动解析成结构化条目）。
- **项目经验 (Projects)**：项目名称、Demo 在线演示链接、起止时间、技术栈、项目目标、团队角色、核心贡献、项目成果。
- **自我评价 (Self Evaluation)**：多行段落自由书写，前台自动排版。
- **二维码设置 (QR Code)**：支持本地上传微信/作品集二维码，自定义下方说明文字。

### 3. 外观风格与模块开关
- **多套预设主题色**：翡翠绿、商务蓝、极光青、活力橙、罗兰紫、玫瑰红、极客黑、沉稳灰，并支持**原生调色盘自定义任意十六进制颜色**。
- **内容模块显隐开关**：可自由开启或关闭“头像照片”、“二维码”、“技能特长”、“教育经历”、“工作经历”、“项目经验”、“自我评价”模块。
- **网页标题与页脚版权**：可自由自定义浏览器标签页 Title 与页脚 Copyright。

### 4. 高级便捷工具
- **实时抽屉预览**：后台内置侧边 iframe 实时预览，修改后无需切标签即可看到实际效果。
- **图片本地上传服务**：内置 Base64 图片解析与安全写入，自动保存到 `uploads/` 目录。
- **导入 / 导出备份**：支持一键导出 `resume.json` 备份配置，或从备份文件导入。
- **快捷键保存**：编辑时支持 `Ctrl + S`（Mac 下为 `Cmd + S`）随时快速保存。
- **一键打印 / 导出 PDF**：前台内置打印样式适配，隐藏导航按钮，完美排版打印或保存为 PDF。

## 🚀 本地快速启动与使用

### 方式一：双击启动（Windows 推荐）
直接在资源管理器中进入 `resume` 文件夹，**双击运行 `start.bat`**。
系统会自动启动服务，并在浏览器中为您打开后台管理界面。

### 方式二：命令行启动
打开终端（PowerShell 或 CMD），进入项目目录并运行：
```bash
cd E:\smart-classroom\resume
node server.js
```
或者：
```bash
npm start
```

服务启动后，在浏览器中访问以下地址：
- 📄 **前台简历展示页面**：[http://localhost:8080](http://localhost:8080)
- ⚙️ **后台内容管理系统**：[http://localhost:8080/admin/](http://localhost:8080/admin/)

> 如需修改服务端口，可通过环境变量指定，例如 `PORT=8088 node server.js`。

## 🔌 后端 API 一览

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/resume` | 获取简历数据 |
| POST | `/api/resume` | 保存简历数据 |
| POST | `/api/reset` | 重置为默认简历数据 |
| POST | `/api/upload` | 上传图片（Base64 dataURL） |
| GET | `/api/export` | 导出简历 JSON |

| POST | `/api/jobs` | 🆕 保存投递记录（整表覆盖） |

| GET | `/api/jobs/export` | 🆕 导出投递记录为 CSV（Excel 可直接打开） |

## 💡 使用小贴士

1. **修改内容后记得保存**：在后台点击右上角 **“保存所有内容”**（或直接按 `Ctrl+S`），前台页面立即实时生效。
2. **切换一栏与两栏**：在后台左侧第一个菜单【布局与外观】中，点击“两栏经典布局”或“一栏单列布局”即可切换，前台页面刷新即可呈现对应的全新排版。
3. **更换头像**：在后台【基本信息】页面，点击“本地选择新图片上传”即可快速更换头像。
4. **一键生成 PDF 简历**：在前台页面右上角点击“打印/导出PDF”按钮，在浏览器打印窗口中将目标打印机选择为“另存为 PDF”，即可导出高清简历文档。
